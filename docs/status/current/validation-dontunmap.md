# `MREMAP_DONTUNMAP` 验证范围

> 仍未完成的事项见 [1.0 缺口台账](../gaps/README.md)；本页只描述当前状态。

状态：**开放**。针对私有匿名的功能切片与两种确定性回滚切片通过；更广的 MM 验收仍未验证。以下结论来自
QEMU 功能运行，不是真机结果、性能对照，也不是已认证的 C0 基线。

## 语义契约

`MREMAP_DONTUNMAP` 把源映射的页搬到新地址，但保留源 VMA 与其中计数。验证覆盖：

- 目标数据保留：搬移后目标映射读到与源一致的内容。
- 源 refault：源地址在搬移后按零页重新缺页，且不复活旧数据。
- fork/COW：搬移之后 fork 与 COW 的语义与普通匿名页一致。
- RSS 清理：多次搬移之后 RSS 回到与操作计数相符的水平，而不是单调增长。
- 确定性回滚：目标 leaf 1、leaf 2 之后注入一次性失败时，源数据与可写性、RSS 保持不变，目标被清除，
  同一进程可以重试成功。
- split 失败：Rust 目标 split 失败 1/2 走显式部分回滚；C/Rust 源 pre-split 失败 5/6 走有序重试；
  Rust 在复制一个 leaf 之后 `DestinationMapping::drop` 实现精确回滚。
- 非分配对照：第 3/4 次调用被观察为非分配对照，不是分配器失败。

## 覆盖范围与未覆盖项

RV64 Linux SMP2 与 AArch64 ABI=both SMP2（C 默认与可选 Rust）覆盖了上述私有匿名路径与完整 `mm_stress`
聚合；早先一次聚合失败与改动前的 `mremap.c` 对照复现了一个独立的大页 COW 问题，通过的聚合包含后来的
block-preserving COW 修复。

仍开放：源 PTE 已换出（swap-in）时的 slot/引用保留与源 refault、共享文件失败路径、更多回滚/分配器阶段、
并发变更、以及非分配对照的新一轮严格运行。这些是特定负载的 QEMU 结果，不构成完整 MM 验收或真机验证。
