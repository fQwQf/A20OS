open requirements drawn from the cited active plans and status pages, plus one
separately tracked confirmed ext4 integrity gap; it is
not the complete 1.0 TODO inventory. Some rows overlap the priority queue in
the first-wave ledger. Rows remain open until the stated behavior and evidence are
delivered. A historical pass, a compile-only result, or a QEMU run that omits
the row's contract does not close it. Current C paths remain the behavioral
reference where stated. A Rust owner is not assigned unless a row names an
existing Rust implementation; the remaining rows need a separately scoped
ownership migration before claiming Rust completion. These rows provide a
manual work-package crosswalk; scanned source lines remain `needs_triage` in
the generated JSON inventory until each line is explicitly linked there.
