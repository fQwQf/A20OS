# 缺口诊断笔记

这里保存 **仍未关闭** 的缺口对应的排查记录：复现条件、已排除的假设、当前怀疑点、下一步观测手段。台账条目只写"现状/缺口/关闭条件"，细节在这里。

规则：

- 一个缺口一份笔记，文件名以台账条目为主题；条目删除后，对应笔记一并删除。
- 笔记只记录仍然有效的诊断。已被推翻的中间结论要标注"已推翻"，不要静默删掉——它解释了为什么排除了某个方向。
- 笔记不是运行日志：不贴完整日志、不记 commit SHA。
