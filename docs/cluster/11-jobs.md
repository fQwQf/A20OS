# 有界分片作业与树形归约

共用调度状态机在 `kernel/include/uapi/a20/cluster_job.h`，不依赖 OS、堆或线程；
Native 驱动在 `user/liba20rt/a20_cluster_job.h`，服务入口为 `user/svc/jobd.c`。
MCU 执行 agent 与服务器执行 agent 共用 CW/1，调度节点不要求 MCU 能执行 ELF。

## 1. 当前图模型

调用方提供不可变图定义、输入和运行表存储。节点可以是 OPERATOR 或 PROCESS；
每个节点产生 8 B 结果。归约节点使用 SUM64，最多两个前驱，前驱索引必须小于
本节点索引，初始化时完整验证图。每个节点保留自己的结果，父节点只有在子节点
全部提交后才 READY。求和按模 2^64，32 位与 64 位实现一致。

便捷 DOT 构图器接受 0–128 个 i32 元素，按最多 16 个元素分片，输入为每片独立的
count + 两个向量，最大 132 B，能放入当前 MCU 单帧预算。最多 8 个叶任务加 7 个
SUM64 节点形成二叉树；奇数层最后一个节点直接向上提升，空向量生成一个零结果。
中间 SUM64 实际交给被选中的 agent 执行，协调器不会把每个输入汇总后本地重算。

## 2. 派发与重派

任务状态：WAITING → READY → RUNNING → DONE；失败可以回 READY 或终止作业。
每次派发增加 attempt，并记录节点完整 ID、boot_epoch、服务槽位和租约期限。
调度器按服务 max_inflight 限制同一服务的同时派发数；超输入/输出上限不派发。
归约同时要求算子声明 ASSOCIATIVE。

不确定的执行失败只在图策略和目标算子都声明 REPLAY_SAFE 时重派，最多 8 次尝试。
PROCESS 始终禁止这种自动重派。传输重试仍是 CL 的同一事务；作业重派则是新的
CW attempt，二者不能混淆。成功的业务结果只提交一次，迟到旧 attempt、错误
节点/会话、其他 job/shard 以及重复结果都不能进入树。当前 attempt 的畸形回复、
非零业务错误或非 8 B 输出会终止作业。

Native 每个 attempt 使用新 endpoint，关闭失败/到期 endpoint 后再派发。连接用
expected_boot_epoch 做 admission 核对。租约到期、节点失联或路由失败后，原任务
可能已经执行；REPLAY_SAFE 是算子作者的真实契约，不是 exactly-once 保证。

全作业预算最多 30 s，Native 默认单次 attempt 500 ms；调用者可以为共享调度器
配置其他不超过全作业预算的期限。取消或作业期限到后关闭所有 attempt endpoint；
已在远端执行的同步 MCU 回调只能协作停止，不能承诺抢占任意固件代码。

## 3. jobd 的 CJ/1 提交接口

`jobd` 导出本地服务 `cluster.jobs`（LOCAL_ONLY），一次完整处理一个有界作业。
远端 agent 仍可跨 UDP/UART 执行。当前没有跨机 jobd 提交、持久队列或多租户调度。

请求：32 B 头 + 两个连续 i32 向量，每个 count 个元素。

| 偏移 | 内容 |
|---|---|
| 0–3 | `CJ`、版本 1、操作 DOT=1 |
| 4 | caller_id:u64，非零，用于关联本次应答 |
| 12 | 全作业 budget_ms:u32 |
| 16 | count:u32，0–128 |
| 20、24 | 保留 u32、u64，必须为零 |
| 32 | 先向量 A，再向量 B；显式小端 |

回复固定 40 B：相同魔数、版本、操作、caller_id；偏移 12 为 CW status，16 为已
完成任务数、20 为重派次数、24 为任务总数、28 保留零、32 为成功时的 u64 结果。
失败时结果字段为零。caller_id 只是关联键，重复提交是新作业；CW 使用协调器
生成的 job ID。根 jobd 退出时作业失败，没有断电恢复或跨协调器幂等承诺。

## 4. 已验证与剩余范围

- 单元测试覆盖 129 种向量长度/树形、单在途预算、节点失败、重派、旧/重复回复、
  不安全算子与进程禁止重派、尝试耗尽、期限和取消。
- 实际 UART 主/叶实现与主机 agent 共同执行 7 节点图；丢弃叶子执行后的根归约
  回复并重派到主机，结果只计入一次。这里的 UART I/O 是确定性字节流仿真。
- 真实 Native jobd 完成 128 元素、15 节点树，结果与顺序参考一致。
- 三独立 QEMU 内核已通过跨节点树执行、执行后丢回复触发新 attempt、成员死亡/
  重启以及控制面恢复；详细记录见状态表。

通用可变长结果、CONCAT、自定义归约、词频演示、外部数据集流式分片、跨 jobd
持久化恢复和物理混合集群尚未完成。现有有界图不能代表这些扩展已经实现。
