# 单系统映像（SSI）与分布式运行时规范

A20OS 单系统映像（Single System Image, SSI）机制允许跨物理主机的执行环境呈现为逻辑上连续的统一运行时系统。在 SSI 环境下，线程调度、任务命名空间、对象句柄解析与远程内存管理均在统一执行域（Execution Domain）抽象下协同工作。

---

## 1. 统一执行域抽象 (Execution Domain)

A20OS 将计算资源统一划分为执行域：

* **内部共享域 (Shared Domain)**：同硬件平台/内存一致性互联的多核环境，共享地址空间与任务表。
* **联邦联邦域 (Federated Domain)**：通过网络或串行总线互联的异构节点，通过分布式对象目录（Object Directory）与代理句柄（Proxy Handle）实现跨域调用。

### 运行时命名空间与句柄解析

```mermaid
flowchart LR
    Caller["用户进程 (Caller)"] --> Handle["本地句柄 (Handle)"]
    Handle --> Proxy["代理端点 (Proxy EP)"]
    Proxy --> Directory["对象目录服务 (Object Directory)"]
    Directory --> Remote["远程目标执行域 (Remote Domain)"]
```

1. **命名解析**：每个发布的服务具有全局 64 字节稳定命名，通过 `runtime_bind` 和 `objectd` 进行发布与租约管理。
2. **代理句柄**：客户端连接远程服务时获得本地 Handle，该 Handle 的底层操作（`channel_call`、`task_wait`）被透明重定向至远程执行代理。

---

## 2. 可配置远程内存与页共享

针对跨主机数据密集型应用，集群 SSI 运行时提供了受控的跨机页共享机制（可配置远程内存服务）：

* **快照与事务模式**：避免不可控的远程锁竞争，采用显式页快照拉取与提交事务。
* **确定性故障回滚**：远程节点离线或网络分区时，本地内存视图立即回滚至最近一次已确认的快照版本，防止死锁或脏读。

---

## 3. 透明线程执行片 (Thread Slices)

在两台或多台机器之间调度同一进程的计算负载时，采用**串行线程交接切片**机制：
* 当前切片在一个节点上获得 CPU 执行权，其他节点对应线程保持休眠状态；
* 在预定的同步检查点（Checkpoint）或系统调用边界，线程上下文（寄存器组与脏页增量）打包序列化并交接给下一节点；
* 该模式为轻量级跨机协同提供了确定性验证路径，而不引入复杂的多机并行共享内存硬件开销。
