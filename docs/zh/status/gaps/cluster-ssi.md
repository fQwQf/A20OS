# 多独立机器单一系统映像：新增工作包

此工作包来自用户新增需求，扩展 [既有 1.0 范围](../../cluster/overview.md)。当前可选远程页服务的接口与配置见[docs/zh/cluster/runtime-ssi.md](../../cluster/runtime-ssi.md)。

新增 [透明线程执行片](../../cluster/runtime-ssi.md) 已接入普通 pthread 的远端用户上下文、真正缺页和系统调用交回。当前独占整个线程组的执行权，串行交接，支持 x86_64/UP。以下条目描述完整 SSI 的剩余范围，不能把初版串行执行片等同于多机并行共享内存。

- **跨内核线程执行**：保持同一逻辑进程/线程身份，转移用户寄存器、栈、TLS、浮点状态；建立执行权代次与失败关闭，禁止迁移期间两边同时执行同一线程。
- **透明内存**：接入真实缺页、地址空间变化、页所有权、映射撤销和 TLB 确认；定义并实现普通原子指令和目标 ISA 内存序。现有快照/暂存 API 不满足此项。
- **同步与资源**：跨机 futex、信号、退出/等待、系统调用代理、统一文件描述符、共享文件偏移、管道与 socket。远程资源操作不能传本机指针作为跨机能力。
- **自动调度**：普通 pthread/clone 的线程按实际负载和数据位置放置与迁移；同步 CPU 拓扑与亲和性视图，不依赖应用调用算子/作业 API。
- **分层策略**：进程级远程执行、私有远端内存和一致共享地址空间独立控制；节点上限与进程策略交集生效。关闭共享内存时，仍共享地址空间的线程必须留在同机；不复制堆后继续执行并宣称符合原程序语义。
- **故障模型**：定义网络分区后的 fencing 和跨节点终止。自动接管、分布式检查点及 I/O 副作用恢复须有独立协议，不从当前重试/去重机制推断具备。

首轮选择同 ISA/ABI 的有 MMU 主机；跨 ISA 原生线程迁移与 NOMMU 透明内存需要额外机制。一般单线程程序不会仅因本工作包而自动拆成并行计算。
