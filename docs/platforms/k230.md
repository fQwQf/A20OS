# Kendryte K230 / K230D

当前仓库没有 K230 / K230D 的 A20OS 平台实现、对应实例或可部署镜像。通用 RISC-V64 架构代码的存在，不表示该 SoC 或任意搭载它的开发板已经获得支持。

## 当前边界

未提供该目标的 `kernel/arch/<arch>/boards/` 板级目录、链接和启动内存布局、UART/中断/定时器接入、固件设备树校验、固件准备和介质打包入口。没有仓库支持的启动命令或实机验收基线，也不能声明存储、网络、用户态或多核可用。

因此本页没有可执行的构建、写卡、烧录或恢复步骤。不能将其他 RISC-V 板的实例改名、复制其内存地址或用其他板的镜像部署到此目标。若设备已经运行厂商固件，继续使用该固件原有的启动和恢复方法。

## 查询仓库状态

在 A20OS 源码根目录可运行以下只读查询；它们不构建或访问设备：

```sh
tools/a20 boards
tools/a20 list
```

工具需要 Python 3.11+。当前查询不包含本目标；安装交叉编译器本身不能补足缺失的平台实现。

## 平台实现所需接口

可部署支持需要明确到具体开发板与内存/启动介质变种，并接通该板的固件入口、内存及保留区、串口寄存器访问、IRQ 路由、计时器和启动交接。最终还需独立的实例、经过校验的镜像布局和恢复方法。通用接口契约见 [移植指南](porting-guide.md)，该指南不提供本板的部署能力。
