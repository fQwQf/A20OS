# 平台文档

本目录的单平台文档是相应目标的操作参考。每篇独立说明适用硬件或虚拟机、
当前系统与设备支持范围、宿主依赖、构建产物、启动部署、可观察结果、恢复方法和限制。
不在本页维护设备清单、价格或统一支持等级。

板级代码存在、配置可解析、内核可链接、虚拟机可运行和实机已验证是不同状态。
单平台页面应分别说明，不能由其中一项推导其他项。
未完成启动链的平台应明确标记不可部署，并列出当前可用的构建入口与缺失条件。
固件能读取存储或使用网络，不代表 A20OS 接管后已有相应驱动。

在仓库根目录查询实际配置：

```sh
tools/a20 boards
tools/a20 list
tools/a20 show <实例名>
tools/a20 check <实例名>
```

这些查询不证明设备能够启动。具体操作以对应单平台文档和当前实例为准。
命令中的设备、IP、挂载路径等占位符必须替换为实际值；写入块设备前核对整盘身份、
卸载其分区，并区分完整介质镜像、内核文件和固件文件。

[构建指南](../dev/build.md)解释通用构建机制，
[移植指南](porting-guide.md)解释板级接口。
这些是补充参考，不替代单平台页面中的必要操作步骤。
