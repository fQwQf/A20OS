# v0.18 发布说明

本版本范围以 annotated tag `v0.18` 指向的提交为准，基于 `v0.17` 之后已提交的变更。内核身份为 `A20OS_VERSION=0.18`，Linux ABI 兼容 release 为 `20.0.18`；Native 系统信息、Linux `uname` 与 `/proc/version` 共用[`kernel/include/core/version.h`](../../kernel/include/core/version.h)。

## 相对 v0.17 的主要变化

- Native 与集群运行时：统一 Native 线程、任务句柄、堆和文件 I/O 的跨执行域语义；加入稳定对象 ID、租约目录、能力查询、负载感知放置、配置应用启动与取消，以及 MCU 与服务器 CPU 共享应用执行的路径。
- 多实例执行：扩展跨架构共享内核的设备路由、远程磁盘与文件系统写入、Linux 线程迁移，并增加跨 QEMU 实例运行 Native/Linux 程序、JVM 和 Minecraft 客户端的验收路径。集群传输加入有界可靠单向消息、分片、路由会话、持久部署配置和工作监督；这些路径的适用限制仍以各自验证记录为准。
- Native 用户态：接入上游 JamVM，支持 Native 线程信号协调、GC 工作线程、取消与调度，并在 AArch64 上运行 Java 工作负载；Native 文件系统 watch、映射保护、VMAR/remap、PI futex 和调度权限也得到实现或修正，并扩展 RISC-V/AArch64 共用门禁。
- 虚拟化：补充可恢复的 RISC-V guest 执行、CPU 本地 vCPU 激活、排队控制和独立 guest 监督器，增加具名 QEMU host 管理工具。实验性 SMP 与硬件后端范围仍受验证记录约束。
- 桌面与图形：增加经过验证的 Wayland Minecraft 配置和 Firefox HTTPS 浏览路径；修正 DRM/PRIME 共享缓冲、virtio-gpu 资源与完成通知、输入设备流、文件系统目录枚举及桌面服务文件引用。
- 内核 ABI 与平台：补充 Linux namespace、seccomp/no_new_privs、procfs 线程枚举、进程 dumpability、信号上下文与 futex 原子操作语义；收敛 ISA/板级策略边界，并继续完善 Raspberry Pi 4 和 32 位调度、原子计数支持。
- 构建与验证：固定构建临时目录，修复 XFCE 门禁的本地化和临时磁盘假设；改进 AArch64 文件系统启动与测试时限，并接入生产 host harness 和共享 Native 架构测试。

## 重要修正

- 内存管理：保留 fork shootdown 期间的 COW 数据、处理并发 fault 重试，修复 swap 与 remap 的页生命周期；拷贝和异步 I/O 期间保持用户映射稳定，并修正页回收提示、slab CPU 归属和映射权限边界。
- 网络与集群：保留背压下已接受的 TCP 写入，修正 virtio 描述符回收和 UDP/RAW 缓冲区所有权；有界 RX、转发回复回收及端点会话处理增加了对应回归和诊断。
- 进程与兼容层：修正整组线程退出通知、打开文件元数据、symlink exec 路径、Native fd 与对象引用、定时器 deadline 和 AArch64 信号 worker 退出；扩展跨架构调度栈指针及 RISC-V32 头文件依赖检查。
- 验证记录区分静态检查、构建与运行结果；没有把未执行的门禁或实验性能力记作通过。

内核版本配对与 tag 名称可用 `python3 tools/check-release-version.py v0.18` 检查。
