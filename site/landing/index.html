A20OS

高性能、高兼容性的混合内核操作系统

A20OS 是一款探索现代操作系统架构边界的高级混合内核 (Hybrid Kernel)：调度、内存管理、VFS 核心与页缓存等性能关键路径留在内核态，保留极速的函数调用性能；同时深度融合微内核理念——设备驱动与文件系统均可作为可崩溃、可重启的用户态服务运行。

架构特性

混合内核架构

宏内核性能 × 微内核弹性；调度/MM/VFS/TCP-IP 数据面驻留内核态，驱动与文件系统作为用户态服务运行。

完整 Linux ABI 兼容

未修改的 musl 程序直接运行；覆盖 mseal、io_uring、landlock、pidfd 等现代 syscall；vDSO 零陷入快路径。

真实用户态

可引导 stock Alpine + XFCE Wayland rootfs，git / vim / fastfetch 开箱即用。

跨平台移植性

RISC-V64、ARM64、x86_64、LoongArch64/32、PPC64LE、ARMv7-M；星光 2 与龙芯 LS2K1000 实机支持。

apk 包管理体系

Alpine apk 格式声明式 recipe，world 清单组装镜像，CI 多架构构建与签名发布。

严肃的质量门禁

syscall 语义 smoke、并发压力测试、用户态 FS 崩溃恢复、SMP 锁模型编译期审查。

支持的硬件平台

VM虚拟机 (QEMU)

  • qemu-virt-riscv64
  • qemu-virt-aarch64
  • qemu-virt-x86_64
  • qemu-virt-loongarch64
  • qemu-virt-ppc64le (pSeries)

BRD物理开发板

  • StarFive VisionFive 2 (星光 2)
  • Loongson LS2K1000 (龙芯)

MCUMCU bring-up

  • STM32F103 (ARMv7-M Cortex-M3, NOMMU)
  • STM32F103ZET6 普中玄武

LA32LA32R

  • NaiLoong Core SoC (软件 TLB refill)

快速开始

$ git clone https://github.com/fQwQf/A20OS.git
$ cd A20OS
$ make ARCH=riscv64 BOARD=qemu-virt-riscv64 run

在 QEMU 中引导 A20OS 只需一条命令，环境准备见完整文档。
