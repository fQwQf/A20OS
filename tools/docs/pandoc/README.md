# Pandoc Documentation & PDF Generation Assets

This directory contains assets and templates utilized by `tools/docs/gen_docs_pdf.sh` for compiling the unified A20OS Reference Manual:
- `a20os.latex`: XeLaTeX document class and typesetting layout template.
- `a20os_pdf.lua`: Pandoc Lua filter for heading anchor unification and figure/table caption adjustments.
- `a20os-logo.svg`: Vector logo embedded in the manual cover page.
